# 🛡️ Script BlueTeam - Automação com DefectDojo

Automatiza a gestão de vulnerabilidades usando Python e DefectDojo.

## 🚀 Funcionalidades
- Conexão automática com API do DefectDojo
- Análise de vulnerabilidades críticas
- Estatísticas por gravidade
- Demonstração funcional completa

## 📁 Estrutura
- `DefectDojo/` - Scripts Python principais
- `Templates/` - Modelos e exemplos
- `Config/` - Configurações (sensível, não versionado)

## 🔧 Como usar
1. Clone: `git clone https://github.com/tvilasboas1/script-blueteam.git`
2. Configure: `cp Templates/config.example.json Config/DefectDojo.json`
3. Execute: `python3 DefectDojo/projeto_mentor.py`
